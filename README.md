# HoMM3 Board Game - Scenario Creator

A browser app for writing scenarios and building maps for *Heroes of Might & Magic III: The Board Game*,
step by step, in the look of the game and the fan-made
[Mission Book](https://github.com/qwrtln/Homm3BG-mission-book).

It exports exactly what a Mission Book pull request needs, plus a PDF:

| File | Where it goes in the Mission Book |
| --- | --- |
| `<name>.tex` | `draft-scenarios/<clash/coops/alliances/campaigns/solo>/` |
| `<map>.png` | `assets/maps/` |
| `<map>.map` | `assets/map-files/` (same format as the [community map editor](https://zedero.github.io/homm3boardgame/)) |
| `<name>.png` (uploaded title icon only) | `assets/images/` |
| `<name>.pdf` | a book-style PDF to print or share |
| `<name>.scenario.json` | the project file, to reopen and keep editing |
| `HOW-TO-SUBMIT.md` | the line to add to `main.tex` and the build/PR steps |

## The steps

1. **Basics** - Basic parameters of the scenario like name, type (Clash, Cooperative, Alliance, Campaign, Solo), heading line, complexity of the scenario, author, source, title icon.
2. **Story** - Flavor text, plus an optional story page after the map: a long story, Story Locations, Special Tiles and numbered paragraphs that point to each other (§12), as in solo and campaign scenarios.
3. **Player Setup** - Rounds, player counts, Starting Resources and Income, Starting Units,
   Town Buildings, Map Tile Pool, Bonuses.
4. **Map** - hex map editor for creating and exporting the scenario map.
5. **Map Setup** - tile list counted from the map (or typed), notes, Heroes Placement.
6. **AI Opponent** - AI Hero Setup for campaigns and coops.
7. **Victory & Defeat** - Victory conditions.
8. **Timed Events** - Description of the Timed Events.
9. **Rules** - Additional Rules for the scenario.
10. **Review & Export** - checklist (including the Mission Book capitalisation lint), live page preview, LaTeX, exports.

Work is saved automatically in the browser; use **Save file** to keep a project file.

`examples/template-scenario/` holds a finished sample Scenario that uses nearly every feature (open it with **Open the template**
on the start screen); see its README.

## Use it online

Open **https://aliksumin.github.io/HOMMIII_BG_MapCreator/**. Nothing to install; your work stays in your browser
(use **Save file** to keep a project file). The site is rebuilt from `main` on every merge.

## Run it on your PC

Needs Node 24. Clone the repository, then:

```bash
npm ci
```

```bash
npm run dev
```

Then open http://localhost:5173.

Without cloning: download `scenario-creator-<version>.zip` from the
[Releases](https://github.com/aliksumin/HOMMIII_BG_MapCreator/releases) page, unzip it, and serve the folder
(opening `index.html` straight from disk does not work, because browsers block the app's scripts on `file://`):

```bash
npx serve <unzipped-folder>
```

Other scripts: `npm test` (unit tests for the `.map`, hex and LaTeX code),
`npm run typecheck`, `npm run build` (static site in `dist/`, works from any sub-path).

## Assets

`public/assets/` and `src/data/catalog.json` are generated by `tools/import-assets.mjs` from local clones of the
community map editor and the Mission Book (it resizes the art to WebP):

```bash
node tools/import-assets.mjs ../homm3boardgame ../Homm3BG-mission-book
```

See [NOTICE.md](NOTICE.md) for where the art comes from and its licenses.

## Code map

| Path | Holds |
| --- | --- |
| `src/model/` | scenario types, defaults, the store (undo, autosave) |
| `src/lib/document.ts` | the scenario laid out as a book page; LaTeX, preview and PDF all render it |
| `src/lib/latex.ts` | the `.tex` writer, following `templates/default.tex` and `templates/campaign.tex` |
| `src/lib/mapfile.ts`, `src/lib/hex.ts` | `.map` format and board geometry, compatible with the community map editor |
| `src/lib/mapdraw.ts` | map PNG renderer |
| `src/lib/pdf.ts` | the PDF writer (jsPDF) |
| `src/lib/bundle.ts` | the ZIP bundle and submit guide |
| `src/components/` | the step screens, map editor and book preview |
